# ATS-GenAI Scripts

This directory contains various scripts organized by functionality to support the ATS-GenAI project.

## Directory Structure

- **kubernetes/** - Kubernetes deployment, configuration, and job management scripts
- **database/** - Database management, migration, and verification scripts
- **flyte/** - Flyte workflow definitions and tasks
- **testing/** - Testing scripts and verification tools
- **utils/** - Utility scripts and service files
- **deployment/** - Deployment scripts for production environments
- **instrument_management/** - Scripts for managing financial instruments

## Usage

Each subdirectory contains specialized scripts for specific purposes. See the README files in each directory for more details.
