# Testing Scripts

This directory contains testing scripts and verification tools for the ATS-GenAI project.

## Key Scripts

- **integration_test_run.py** - Runs integration tests
- **test_api_connectivity.py** - Tests API connectivity
- **test_populate_instrument_polygon.py** - Tests populating instrument data from Polygon

## API Verification

The `api_verification/` directory contains scripts for verifying API connectivity and functionality:
- **monitor_api_job.py** - Monitors API jobs
- **test_api_connectivity.py** - Tests API connectivity
- **verify_api_and_db.py** - Verifies API and database connectivity

## Automated Dev Tests

The `automated_dev_tests/` directory contains automated tests for development:
- **test_polygon_integration_dev.py** - Tests Polygon integration in development environment
