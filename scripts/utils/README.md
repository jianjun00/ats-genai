# Utility Scripts

This directory contains utility scripts and service files for the ATS-GenAI project.

## Key Scripts

- **print_env_logging.py** - Prints environment variables for logging purposes
- **minikube-autostart.service** - Systemd service file for Minikube autostart
- **wsl-kubernetes.service** - Systemd service file for WSL Kubernetes
- **start-wsl-kubernetes.bat** - Batch file for starting WSL Kubernetes
- **start-wsl-kubernetes.ps1** - PowerShell script for starting WSL Kubernetes
